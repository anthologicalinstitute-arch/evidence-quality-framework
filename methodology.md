# Evidence Quality Framework: Methodology

## 1. Purpose

This document describes an exploratory framework for organizing assessments of evidence quality. It is intended to make assumptions explicit and encourage consistent documentation.

The framework is a proposed method, not a validated scientific measure.

## 2. Proposed Equation

\[
Q_e = q_s \times q_t \times q_c \times q_p
\]

Where:

- \(q_s\): source reliability
- \(q_t\): freshness or temporal relevance
- \(q_c\): corroboration by independent evidence
- \(q_p\): provenance and completeness of the evidence record

For an illustrative calculation, each factor is assumed to fall between 0 and 1.

## 3. Illustrative Example

Assume the following example scores:

- Source reliability: 0.90
- Freshness: 0.80
- Corroboration: 0.75
- Provenance and completeness: 1.00

Then:

\[
Q_e = 0.90 \times 0.80 \times 0.75 \times 1.00 = 0.54
\]

The result is an illustrative composite score. It is not a probability that a claim is true, nor does it establish the validity of the framework.

## 4. Scoring Considerations

Before applying the framework, researchers should document:

- The scale and criteria used to assign each factor.
- The sources and evidence supporting each score.
- The date of assessment.
- Whether corroborating sources are genuinely independent.
- How missing or conflicting information is handled.
- Whether the factors overlap or double-count the same evidence-quality concern.

## 5. Evaluation Plan

Potential future evaluation should include inter-rater agreement, sensitivity analysis, comparison with alternative scoring methods, and tests on suitable reference datasets.

Any claim that the framework predicts truth or improves decisions requires separate empirical evidence.

## 6. Status

**Status: Exploratory — not validated.**

This document describes a proposed framework and illustrative calculation. It does not establish an approved institutional standard.
